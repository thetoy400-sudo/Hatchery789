# ระบบจำลองการไหลและออกแบบตัวเกี่ยลูกไก่บนสายพาน (Chick Flow Simulator & Deflector Design)

โปรแกรมจำลองการไหลของลูกไก่บนสายพานลำเลียง 2 เส้น พร้อมระบบออกแบบสิ่งกีดขวาง/ตัวเกี่ยไก่ (Deflectors/Baffles) เพื่อให้ลูกไก่กระจายตัวสม่ำเสมอตลอดหน้ากว้างสายพานก่อนเข้าสู่ช่องคัดแยกทั้ง 6 ช่อง

## 📌 คุณสมบัติและฟังก์ชันหลักของระบบ

### 1. การจำลองสายพาน 2 เส้นตามลักษณะจริง
* **สายพานสีฟ้า (Infeed Conveyor):**
  * วิ่งในทิศทางแนวนอน (จากซ้ายไปขวา)
  * กำหนดหน้ากว้าง (Width), ความยาว (Length), ความเร็ว (m/min), และอัตราปล่อยลูกไก่ (ตัว/ชั่วโมง)
  * ลูกไก่จะปรากฏและเคลื่อนที่บนสายพานสีฟ้าตามอัตราที่กำหนด และตกลงมาแบบสุ่มตลอดความกว้างของปลายสายพานสีฟ้าลงสู่สายพานสีเขียว
* **สายพานสีเขียว (Main Distribution Conveyor):**
  * วิ่งในทิศทางแนวตั้ง (จากบนลงล่าง)
  * พาลูกไก่เคลื่อนที่ด้วยแรงเสียดทานของสายพาน 100% ผ่านชุดสิ่งกีดขวางเพื่อเกลี่ยไก่ให้เต็มหน้ากว้าง

### 2. การสร้างและจัดการสิ่งกีดขวาง / ตัวเกี่ยไก่ (Obstacles / Deflectors)
* รองรับรูปทรง 3 แบบ:
  * 🔺 **สามเหลี่ยม (Triangle):** กำหนดขนาดฐาน, ความสูง, มุมหมุนองศา เหมาะสำหรับทำลิ่มกระจายกระแส
  * ⬛ **สี่เหลี่ยม / แผ่นเกี่ย (Rectangle / Baffle Plate):** กำหนดความกว้าง, ความหนา, มุมเอียงองศา เหมาะสำหรับแผ่นเบี่ยงทิศทางไก่
  * ⚪ **วงกลม / เสากลม (Circle / Peg):** กำหนดรัศมี เหมาะสำหรับจัดเรียงเสาพินกระจายตัว (Pegboard Array)
* **การควบคุมที่สะดวกรวดเร็ว:**
  * สามารถใช้เมาส์ **คลิกลากย้าย (Drag & Drop)** หรือ **หมุนองศา (Rotate Handle)** บนหน้าจอได้โดยตรง
  * หรือพิมพ์ระบุพิกัดตัวเลขแม่นยำในช่องแกน X, แกน Y, ขนาด และองศาในแถบเมนูด้านซ้าย

### 3. การออกแบบช่องแบ่ง 6 ช่อง (6-Lane Dividers)
* ปลายด้านบนของแต่ละซี่แบ่งมี **หัวลิ่มสามเหลี่ยม (Wedge Tip)** เพื่อป้องกันไก่ชนกระแทกขอบตรงๆ และช่วยนำลูกไก่แยกเข้าช่อง
* สามารถกำหนด:
  * ความยาวของช่องเลน (Lane Length)
  * ขนาดฐานและความสูงของหัวลิ่มสามเหลี่ยม (Wedge Base & Height)
  * **ความกว้างของแต่ละช่องทั้ง 6 ช่อง (ช่อง 1 ถึง ช่อง 6) ปรับแยกอิสระได้** พร้อมปุ่ม "แบ่งเท่ากัน"
  * เกณฑ์ช่องว่างแคบสุดที่ยอมให้ผ่าน ($k$ เท่าของตัวลูกไก่ เช่น 1.3 เท่า)

### 4. ระบบตรวจจับจุดคอขวดอัตโนมัติ (Bottleneck & Jamming Safety Check)
* คำนวณระยะช่องว่างระหว่างสิ่งกีดขวางแต่ละชิ้น และระยะระหว่างสิ่งกีดขวางกับขอบสายพาน
* หากมีช่องว่างใดแคบกว่าเกณฑ์ปลอดภัย ($< k \times \text{ขนาดตัวไก่}$) ระบบจะ:
  * แสดงเส้นประมิติสีแดงเตือนบนสายพานพร้อมตัวเลขระยะจริง (cm)
  * แสดงแถบแจ้งเตือนความเสี่ยงติดขัด (Jamming Risk Toast) ที่ด้านล่าง

### 5. การประเมินผลและการวิเคราะห์สถิติ (Real-Time Analytics)
* **การกระจายตัว 6 ช่อง:** แสดงจำนวนตัวที่เข้าแต่ละช่อง และสัดส่วนเปอร์เซ็นต์ พร้อมเส้นเป้าหมาย Target ($16.67\%$)
* **ดัชนีความสม่ำเสมอ (CV % - Coefficient of Variation):**
  $$\text{CV} (\%) = \frac{\text{SD}}{\text{Mean}} \times 100\%$$
* **เกณฑ์ประเมิน:**
  * ⭐ **CV < 5%:** ยอดเยี่ยม (สม่ำเสมอสูงมาก ไก่เข้าเท่ากันทุกช่อง)
  * 🟢 **CV 5 - 10%:** ดี (ผ่านเกณฑ์มาตรฐานอุตสาหกรรม)
  * 🟠 **CV 10 - 20%:** พอใช้ (เริ่มมีความต่างระหว่างช่อง)
  * 🔴 **CV > 20%:** ต้องปรับปรุง (ไก่กองฝั่งเดียวอย่างมาก)
* **ฟังก์ชันจำลองด่วน (Batch Run 1,000 ตัว):** คำนวณผลจำลองลูกไก่ 1,000 ตัวในเสี้ยววินาที เพื่อให้ได้ค่าสถิติที่นิ่งและแม่นยำทันที

### 6. โหมดแบบสำหรับสร้างจริง (Engineering Blueprint CAD Mode)
* ปุ่มสลับไปที่ **"📐 แบบสำหรับสร้างจริง (Blueprint CAD)"** บนแถบด้านบน
* เปลี่ยนมุมมองเป็นแบบเขียนแบบวิศวกรรม (Engineering Drawing):
  * มีจุดอ้างอิง **DATUM (0,0)** ที่มุมบนซ้ายของสายพานสีเขียว
  * แสดงเส้นบอกขนาด (Dimension Lines): ระยะ X จากขอบซ้าย, ระยะ Y จากด้านบน, ระยะจากขอบขวา, ระยะห่างถึงปากทางเข้าช่องเลน
  * แสดงระยะห่างระหว่างสิ่งกีดขวางแต่ละชิ้น
  * **ตารางพิกัดสั่งสร้าง (Machining Coordinates Table):** สรุปพิกัดและขนาดของทุกชิ้นงานอย่างครบถ้วน
  * ปุ่ม **"📸 บันทึกภาพ"** เพื่อดาวน์โหลดรูปแปลนความละเอียดสูงไปสั่งผลิตหรือเข้าเล่มรายงาน

## 📋 รูปแบบการวางตัวเกี่ยสำเร็จรูป (Presets)
ระบบมี Preset ตัวอย่างให้เลือกเปรียบเทียบในแถบ "Preset":
1. **1. ไม่มีตัวเกี่ย (เดิม - ไก่กองซ้าย):** แสดงสภาพปัญหาเดิมที่ลูกไก่ตกฝั่งซ้ายและไหลเข้าเฉพาะช่อง 1-3 ทำให้ค่า CV สูง (>50%)
2. **2. แผ่นเกี่ยเฉียงเดี่ยว (Diagonal Baffle):** แผ่นเกี่ยเดี่ยวทำมุม 32° ดันไก่จากฝั่งซ้ายไปขวา
3. **3. แผ่นเกี่ยสลับ 3 ตอน (Staggered Vanes):** แผ่นเกี่ย 3 ชิ้นทำมุมสลับฟันปลา เกลี่ยไก่ได้สมดุลมาก
4. **4. เสากลมกระจายตัว (Pegboard Array):** เสากลม 7 เสา จัดเรียงแบบ Galton Board ช่วยกระจายไก่แบบเกาส์เซียน
5. **5. ลิ่มแยกทางคู่ (Dual Wedge Splitters):** ลิ่มสามเหลี่ยม 2 ชั้น แยกกระแสไก่ออกเป็นสายย่อย

## 💾 ระบบฐานข้อมูลและการซิงค์กับ GitHub (Database & Cloud Sync)
ระบบมีแท็บ **"💾 ฐานข้อมูล"** อยู่ในแถบเมนูด้านซ้าย:
1. **บันทึกดีไซน์ (Save Current Design):** บันทึกการตั้งค่าตัวเกี่ย สปีดสายพาน และค่าสถิติ CV เก็บไว้ในฐานข้อมูลบนเบราว์เซอร์ (LocalStorage)
2. **โหลด / ลบดีไซน์ (Load / Delete):** เรียกดูรายการดีไซน์ที่เคยบันทึกไว้ และกดโหลดกลับมาใช้งานได้ทันที
3. **ส่งออก / นำเข้าไฟล์ JSON (Export / Import):** ดาวน์โหลดฐานข้อมูลเป็นไฟล์ `.json` เพื่อแชร์ให้ทีมงาน หรือกู้คืนข้อมูล
4. **ซิงค์กับ GitHub Cloud (Gist Sync):** 
   - ใส่ GitHub Personal Access Token (PAT) ที่มีสิทธิ์ `gist`
   - กด **"☁️ อัปโหลดขึ้น GitHub"** เพื่อสำรองฐานข้อมูลขึ้น GitHub Cloud
   - กด **"⬇️ ดึงจาก GitHub"** เพื่อซิงค์ฐานข้อมูลมาใช้กับเครื่องอื่น

## 🌐 วิธีการอัปโหลดขึ้น GitHub & เปิดใช้งานออนไลน์ (GitHub Pages)
ไฟล์ **`index.html`** ถูกออกแบบเป็น **Single Standalone File (รวม CSS และ JS ไว้ในไฟล์เดียวเบ็ดเสร็จ)** คุณสามารถอัปโหลดไฟล์นี้เพียงไฟล์เดียวขึ้น GitHub ได้ทันที:

1. เข้าเว็บไซต์ [GitHub.com](https://github.com) แล้วสร้าง Repository ใหม่ (เช่น `chick-flow-simulator`)
2. คลิกปุ่ม **"Add file" > "Upload files"**
3. ลากไฟล์ **`index.html`** ไปวางในหน้าเว็บ แล้วกด **"Commit changes"**
4. **เปิดใช้งานหน้าเว็บออนไลน์ (GitHub Pages):**
   - ไปที่เมนู **Settings** ของ Repository
   - ในแถบเมนูด้านซ้าย เลือก **Pages**
   - ใต้หัวข้อ *Build and deployment > Branch* ให้เลือก **`main`** (หรือ `master`) แล้วกด **Save**
   - รอประมาณ 1–2 นาที คุณจะได้ URL สำหรับเปิดใช้งาน เช่น:
     `https://<your-username>.github.io/<repo-name>/`
   - สามารถส่งลิงก์นี้ให้ทีมงานเปิดใช้งานผ่านมือถือ แท็บเล็ต หรือคอมพิวเตอร์เครื่องใดก็ได้ทันที!
